Hit "Format it". The first run downloads Python and SQLFluff (~15 MB, then cached), so give it a few seconds.

    How it works

    Pyodide is CPython compiled to WebAssembly. The page boots it, installs SQLFluff from PyPI, then runs sqlfluff fix with the same .sqlfluff config you can download and use in your own projects. Anything SQLFluff can't fix on its own, like an aggregate with no alias, shows up as a note underneath.

    The reasoning behind each rule is in the SQL style guide.
