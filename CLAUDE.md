# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Jekyll personal site for stevenpisani.com, built by GitHub Pages (the `github-pages` gem, so Jekyll 3.x and only whitelisted plugins). The homepage is a small walkable planet (Three.js): you're dropped onto an asteroid in first person with a tiki bar in view, walk over, sit, and pick the site's content from a menu. Every section is also one click away in the top bar. Every other page is a normal Jekyll page, and the non-3D homepage lives at `/classic`. No CSS framework and no build step beyond Jekyll.

## Development Commands

### Setup
```bash
# Install dependencies (Ruby 3.x + Bundler)
gem install bundler
bundle install
```

### Local Development
```bash
# Run Jekyll development server
bundle exec jekyll serve

# Build the site
bundle exec jekyll build

# Check the build: internal links and assets exist; the world's modules parse, resolve,
# use minified addons and are preloaded. CI runs both (.github/workflows/check.yml).
bundle exec jekyll build --strict_front_matter && node tools/check-site.mjs
```

## Architecture

- `_layouts/`: `default.html` (shell), `world.html` (the homepage: import map for Three.js from jsDelivr, minified builds only, modulepreloads for the whole module graph, loads `world.css` + `world/main.js`, preloads `props.glb`), `page.html` (kicker/heading/lede header + prose; `wide: true` drops the prose width), `post.html`. Both shells share `_includes/head.html` (SEO via `{% seo %}`, fonts, site.css).
- `_includes/`: `nav.html`, `footer.html`, `launch.html` (next-launch card, Launch Library 2 API), `cover.html` (post cover, gradient fallback seeded by title), `post-row.html`, `lab-card.html`, `read_time.html`
- `_data/`: content lives here, edit these rather than HTML
  - `timeline.yml`: career timeline on /about
  - `lab.yml`: experiments on /lab (first three also appear on the homepage)
  - `books.yml`: shelves on /bookshelf
  - `drinks.yml`: Steve's favorite drinks and recipes (name, origin, glass, build, method, note, and `make`: how the robot makes it: glass, ice, colour, foam, garnish, and the steps after the pours; the header explains each field): the chalkboard behind the bar, the "Favorite drinks" panel (each recipe gets a "Make me one" button), and /drinks
  - `bar.yml`: the homepage's menu (label, a one-line note on what's there, fallback href), the bartender's lines, and the campfire list
- `_posts/`: posts (layout defaults to `post`). Optional front matter: `image_url` (a URL or a site path like `/assets/images/x.webp`, with a 192px square `x-thumb.webp` beside it for the post lists; `cover.html` asks Unsplash and Pexels for thumbnail-sized crops itself), `description`
- Pages: `index.html` (the asteroid), `classic.html` (/classic, the non-3D homepage), `about.html`, `blog.html` (/blog, labelled "Writing"), `lab.html`, `bookshelf.html`, `drinks.html` (/drinks, recipes via `_includes/drinks.html`), `404.html`, `401.html`
- `lab/`: lab experiments with their own pages, e.g. `lab/sql-formatter.html` (SQLFluff in the browser via Pyodide; its Python lives in `assets/py/fluff.py`)
- `assets/files/.sqlfluff`: downloadable SQLFluff config for the SQL style guide. It's the single source of truth; the formatter fetches it too. Listed under `include:` because Jekyll skips dotfiles.
- `recipe_tracker/`: standalone app (own inline styles, Supabase), linked from the lab

### The asteroid (homepage)
Art direction: moody, realistic mid-century "Polynesian Pop" at night. The bar is the warm light source against deep space; cool moonlight is the key light; every warm tone comes from practicals (torches, pufferfish lamps, floats, neon, fire). Tiki signals, strongest first: carved tikis, a steep A-frame thatch roof, glass floats in nets, pufferfish lamps, bamboo, tiki mugs, tapa cloth, lava rock, torches, neon script. Tiki is an American pop fantasy: use invented pop-style tikis, never replicas of real sacred carvings, and no caricatured people.

Design rules, from Krug's *Don't Make Me Think* and Apple's HIG. Keep them when changing anything here:
- No start screen, splash, or instructions panel. The first frame shows the bar and its neon sign ahead, far enough that you have to walk.
- Loading never looks broken (HIG: Launching). The launch screen (`#veil` in `index.html`) is a painted stand-in for the first frame: night sky, horizon, and the neon sign warming up exactly where the real one will be (an SVG copy of the 3D sign, drawn from the same numbers as `bar.js` and the canvas textures and placed by CSS `perspective` at the sign's camera-space pose from the spawn, so the scene fades in with the sign on top of itself; `world.css` notes what to re-measure if the spawn, sign or fov change), a progress bar whose sheen keeps moving while the main thread builds (compositor-only animation), and a plain line saying what's being done (`step()` in `main.js`). It sits under the UI, so the top bar, menu and deep-linked panels work while it loads. It fades only after the first frames are drawn (shaders compile there), never over a frozen scene. After 10 s a way out appears ("see the site without 3D" → /classic), pure CSS, so it shows even if the script never loads.
- Site ID + tagline top-left and every section in the top bar at all times (a Menu button under 1040px, where seven sections would wrap), with the speaker beside them; the buttons keep their size and the tagline wraps first. Nobody is ever forced to walk to reach content.
- Click/tap where you want to go, drag to look. WASD/arrows and E are extras, never required.
- Clickable things look clickable without hover. The bar needs no label: it's the lit, open thing at the end of the path with its neon sign readable from where you land, your stool sits in a pool of light from a pendant lamp, and the bartender turns and waves as you walk up. The menu card's "Pick up the menu" label stays until the first time someone picks it up.
- One hint at a time, shown just in time, retired forever (localStorage `world-*`) once used.
- The menu is an old-school tiki menu (bamboo frame, parchment, tapa band, "Steve's" in script) with plain labels (`label` in `_data/bar.yml`) and one line each saying what's there (`note`). No filler text: no prices, no made-up drink names, nothing decorative that's words.
- Every state has a way back: × and Esc close panels; at the bar × and Esc put the menu back down, then Esc or "Leave the bar" (in the menu, or bottom-left when it's down) leave; the browser Back button closes panels (`#<id>` history entries), and deep links (`/#about`) open content directly.
- The camera never moves on its own: no intro flights, no idle sway. It moves only when the guest asks (sitting, leaving, leaning in to watch a drink being made). Respect reduced motion.
- The point of view is continuous: sitting down and getting up are first-person body motions (`flyPath` in `main.js`: one eased curve through a few poses in `bar.seat`) that start from and end in the exact walking view. Keep them unhurried; getting up turns you around, so it takes about 4 s and the turn peaks near 140°/s.
- Tap targets at least 44px.

Plain three.js ES modules in `assets/js/world/`, no bundler, no physics engine:
- `main.js`: panels, menu, top bar, history (works before and without 3D); then the renderer, picking (hover label + ground ring, click-to-walk, click-to-use), sitting and leaving, hints, bloom + grade post-processing (desktop only). `#world[data-state]` = loading | walk | seat | camp | hammock | shore | fallback.
- `planet.js`: radius-20 planet. `heightAt(dir)` is analytic, so terrain and the player's feet always agree. The visible terrain is a fine cube-sphere (about 0.3 m between vertices on desktop, 0.5 m on phones) with analytic normals and triplanar grain and bump from `textures.js` `groundDetail()`, worn to soil beside the trails; picking uses a coarse invisible copy named `ground` (clicks only need a direction). `place(obj, dir, {heading})` stands anything upright on the sphere; `dirFrom(polar, longitude)` addresses spots (the bar is at the north pole, facing longitude π/2). Also the atmosphere shell, instanced wind-blown grass tufts and pebbles, kept off trails and landmarks (`keepClear` from `places.js`). The lagoon (`POND`): a bowl carved into `heightAt` itself (an irregular outline, `pondReach`; waterline at `SHORE_K`, `shoreAt(phi)`), damp sand at the waterline and silt below it in the terrain colours, and `buildPond()`: a water disc on the sphere at `POND.level` whose edge the bowl's rim hides, dark and glassy (shader ripples bend its normal, the nebula tints it at grazing angles, lamp glints via `lampLit(water, { specular })`), reeds and cattails on the far shore and a few lily pads.
- `player.js`: first-person controller on a sphere. Orientation is a quaternion that is parallel-transported to the new up vector every step; never `lookAt` with a fixed world up (it flips at the poles). Collisions are circles in the tangent plane, tested only against colliders that are actually nearby in 3D (flattened onto the tangent plane, things on the far side of the planet land under your feet). `walkTo(point)` auto-walks and turns you toward your path; timing uses simulation time, not wall clock. Input: one pointer vocabulary for mouse and touch (press without moving = tap, press and move = look), plus WASD/arrows and E/Enter.
- `bar.js`: Steve's, a classic A-frame tiki bar on a lava-rock plinth at the pole: carved tiki posts, steep thatched roof with an upswept ridge and Googie starburst, a neon "Steve's" script in the gable over a lit "World famous" box (dark letters on a glowing face, brass rim, marquee bulbs; `textures.js` `signBox()`), bamboo bar front, tapa-cloth back bar with a chalkboard of favorite drinks hung where you see it from your stool (click it for the recipes), floats and pufferfish lamps, volcano bowl, torches, the robot bartender, palms. `groundY(x, z)` gives the real ground height off the deck (the planet curves away). Seat pose and drink serving live here too: `serve(id)` has the robot shake at once, then at 0.9s slides a mug across the counter to your seat (placed directly under reduced motion); `greet()`/`farewell()` are called on sitting and leaving. `make(recipe, { onStep, onDone })` has the robot make a real drink from `drinks.yml` in front of you, one step at a time: it rolls up to the counter, sets out the glass with its ice (`props.js` `barGlass()`), pours each ingredient from its own tinted bottle (into a tin in the middle of the counter if the drink is shaken, straight into the glass if not; the level rises by each measure), then shakes and strains, stirs or swizzles (the glass frosts), garnishes (`garnishFor()`), and slides it over. Each thing stands under the hand that works it, and a pour stream only shows while the spout is really over the vessel. The bottles it pours Planteray, Campari, Chartreuse and Meletti from are the real ones: `bottle-*` hero models (`"lazy": true` in the manifest, so they load after the reveal: `loadHeroes(…, { lazy: true })`, shaders compiled off to the side, then `bar.setBottles()`), standing in a row at the robot's end of the counter until it picks one up (`REAL` maps a build line to its bottle); everything else pours from a tinted stand-in bottle. Every step has an enter, a per-frame part and a finish, so `skip()` (and a long frame) lands on the finished drink; `cancel()` clears it. `update(t, dt)`: `t` is ambient time (frozen by `?test`), `dt` real frame time for things the guest causes, so they still play under `?test`. `places.js`: the trail network (`TRAILS`: a flagstone walk from where you land to the bar, gravel trails from its fork to the rocket, telescope, boat and dish, and on round the back to the campfire, with lanterns along each, walk included, starting a few steps in so none looms as you land; none is a real light: each throws its pool through `lamps.js`), your ship, a Saturn V-style lander (`rocket.js`), on a lava-rock landing pad with chasing edge lights and floodlights up the hull, a brass refractor telescope on a wooden tripod, the campfire (`camp.js`), the radio dish ("Get in touch": Contact), the canoe (pulled up out of the lagoon, bow in the shallows; the lagoon is a collider, so you stop at the waterline), round the lagoon (`LAGOON` azimuths; a spur trail comes down beside the canoe) a striped hammock between two palms with a book left open in it (you climb in, lie back and read: the Reading list; see below) and messages in bottles washed up at the waterline (scenery), a little pile of flat stones where the lagoon trail comes down to the water (skip one: see below), a tiki signpost in the corner of the fork whose arrow boards point along the real trails (wayfinding, not clickable), and seeded scatter (kept off the trails: lava rock, palms, and `decor.js` `shrub()`s, one merged mesh per shrub) (`SPOTS` holds their positions). Interactables are `{ id, label, verb, object, extra, point, approach, radius }`: click `object` (or anything in `extra`), walk to `approach`, then use it; an `id` that's a panel id (`contact`, `shelf`, `launch`) opens that panel, so a landmark is a shortcut to a section that's also in the top bar and menu. The bartender mentions them (`_data/bar.yml`).
- `rocket.js`: your ship, `saturnLander()`: a Saturn V cut down to about 3.7 m and built like the Outer Wilds ship. It keeps what makes it recognisable (the stack of stages narrowing to the command module and a red escape tower, the black-and-white roll pattern, "USA" and a flag, five engine bells, four fins) on a squat lathe body whose UVs run by height, so one canvas paints the livery in metres, plus hand-built wear (panel seams, rivet rows, patch plates, scuffs) and the SJPJr badge from the favicon, drawn in once it loads. Outer Wilds touches: four sprung landing legs (hinge, piston strut, round foot), a glowing porthole cockpit in a riveted brass ring, a hatch with a lit window and a ladder to the ground, thruster quads, a dish antenna. The front is local -z; `faceFront(x, z)` turns it to the path.
- `camp.js`: the campfire, Outer Wilds style. `buildCampfire()`: lava-rock ring, glowing coals, a log teepee (turned so no log stands end-on in front of you), two flames, sparks, log benches, and company: Rodin's Thinker (a nod to Philadelphia's Rodin Museum; a `thinker` hero model, `props.js` `thinkerFallback()` as the stand-in) seated on his rock in one place round the fire and the moai behind the log in another, either side of yours (`places.js` sinks both into the ground, which curves away from the camp's plane), a bag of marshmallows; `seatToward(x, z)` puts your bench toward the trail and returns the seat poses. `createRoaster(camera)`: the stick you hold (on the camera, so it follows your look); press and hold (Space on keyboards) reaches it into the flame, it toasts by distance to the hot spot (cream, golden, brown, black), catches fire past dark brown, and `eat()` gives a `verdict()`; each marshmallow comes with a line from `likes` in `_data/bar.yml`. In `main.js`, `sitAtFire()`/`leaveFire()` use the same continuous `flyPath` body motion as the bar; "Eat it" (or "Blow it out") bottom-right, "Leave the fire" bottom-left, Esc leaves; the roast hint retires once something's toasted.
- `paths.js`: trails built vertex by vertex on the analytic surface, so nothing floats or sinks: `sampleTrail(points)` (a smooth, gently meandering curve), a crushed-shell gravel ribbon with ragged edges (`trailTexture()`), flagstones draped on the terrain (top a few cm proud, sides running into the ground), pebble borders, lantern spots, and `trailEdgeFn()` (distance to the nearest trail edge, for grass, scatter and ground wear). Triangles must face outward: a ribbon or slab wound the other way is culled and vanishes.
- `decor.js`: the layered density real tiki bars have (from Smuggler's Cove, Three Dots and a Dash, Trader Vic's, Tiki-Ti): a backlit rum wall (instanced lathe bottles with labels and caps) on every shelf, crossed paddles and a carved mask on the tapa, a sagging net of glass floats under the roof, a grass fringe and festoon bulbs on the front beam, rope trim on the bar top, the robot's station (citrus, tins, jigger, bitters, swizzles and umbrellas, towel), and monstera, red ti and fern beds around the plinth (entrance left open). Repeats are instanced and it adds no lights, so phones pay little. Leaves, net and rope textures live in `textures.js`.
- `robot.js`: the bartender, a 1950s tin-toy robot built from primitives, printed like the real ones: `textures.js` `tinLitho()` lithographs every panel (teal enamel, a cream and coral border line, printed rivets and seams, vents; chevrons round the skirt). `PALETTE.tinTeal` is bluer than teal on purpose, so it still reads teal under the amber lamps. Box head with a glowing Grog-o-Meter dial under a red visor, glass dome, an antenna on a coil spring, aloha shirt with a paper umbrella in the pocket, a lei of plumeria flowers (`plumeria()`) draped the way a real one lies: flat on the shoulder plate outside the head (which overhangs the neck), then down the chest in a U; a bow tie on the collar plate, three blinking belly lamps, jointed arms with pincers, a shaker and a bar towel, and one wheel on a chrome bellows under a red tin mudguard. Poses (rest, greet, shake, pour) are eased per joint; to make a drink, `hold()` puts a bottle, bar spoon, swizzle stick or garnish in a pincer (hung tipped down from it, so reaching out over a glass tips a bottle's neck into it) and `reach()` solves the arm joints (coordinate descent on the real joints, for where the robot is headed) to put the held thing's tip at a point, with `stir` / `swizzle` wiggles; `beckon(guest)` turns and waves as you walk up; left alone at rest it wipes down the counter every nine seconds or so; `greet(spot, guest)` rolls over and turns to face you when you sit; with reduced motion it snaps between poses and nothing moves on its own. A `robot` hero model can replace the body only.
- `sky.js`: dim fbm nebula dome, twinkling stars, a cool distant star (the moonlight's source), shooting stars, and two bodies lit by that star in their own shaders: a ringed gas giant (warped turbulent bands, a storm, soft terminator, limb darkening, rings and globe shadowing each other) low on the left as you land, and a cratered moon (`textures.js` `moonMaps()`, Lommel-Seeliger shading, earthshine) up on the right, in tonight's real phase: it has its own light direction, set from `site.js` `moonTonight()` (the lunar age from a known new moon, no API): from behind it at new, over your shoulder at full, from the right while waxing and the left while waning; it stays where it is in the sky. The gas giant's phase is physics: place it by angle to `sunDir`. Distant bodies set `fog: false`.
- `materials.js`: the palette (`PALETTE`) and every surface: procedural canvas textures (wood grain, bamboo, thatch, lava rock, tapa cloth, rattan, scuffed tin) on PBR materials, `enamel()` and `chrome()` for the robot, `glow()` for things that should bloom, `restyle()` for loaded Kenney models. Use these; don't introduce ad-hoc colours.
- `props.js`: procedural tiki props: carved tiki (a height-map face displaced into real geometry), glass floats in rope nets, pufferfish lamps, tiki mugs, volcano bowl, bamboo tiki torches (tapered pole with nodes, rope lashing, a flared split-bamboo cup round a fuel canister and wick), palms with ringed trunks, alpha-textured fronds and a couple of dead ones hanging, lava rocks, moai; out on the planet, `radioDish()` (a retro radio telescope: pedestal, yoke, parabolic dish with seams, ribbed back, feed horn on struts, equipment hut) and `outriggerCanoe()` (hull with raised ends, float on two booms, paddle), `barGlass(kind)` (rocks, collins or coupe, with fill, ice, foam, frost and garnish) and `garnishFor(name)` (pineapple wedge, orange slice, mint sprig, coffee beans) for the drinks the robot makes, `hammock(a, b, up)` (striped canvas, `textures.js` `hammockCloth()`, fan lines, an open book with printed pages, `bookPage()`; `userData.hammock` lets you get in: the cloth, lines and book hang in a `swing` group that swings about the tie line as a damped pendulum (`kick()`, `update(dt)`), `setLoad(k)` sags it under your weight, `point(u, lift, across)` gives spots on it in the swing's frame), `bookStack()`, `messageBottles()`, `signpost(boards)` (lettering from `signLettering()`). `fire.js`: shader flames on crossed quads + flickering lights (`light: 0` = flame only).
- `lamps.js`: lamp light without lights. Lanterns and the walk's torches `addLamp()` a position and strength; `lampLitTree()` gives every standard material (`lampLit(m, { specular })` adds their glints, for water) on the planet and around the landmarks a shader loop that adds their warm pools (soft falloff, wrapped Lambert, a little flicker from `updateLamps(t)`, max 48, 5.5 m range). Same cost however many lamps, so phones get lit paths too; use it rather than adding real lights out on the planet.
- `sound.js`: sound, all synthesised with Web Audio (no audio files), each source placed on the planet with three.js `PositionalAudio` so it gets louder as you walk up: a quiet generated exotica loop at the bar (rolled vibraphone chords with motor tremolo, upright bass, bongos, the odd whistled bird call), the fire's rumble and crackles, water lapping at the lagoon, crickets everywhere; and effects from `bar.setSfx()` (the shaker, ice into a glass, pours while the stream is showing) and the hammock's ropes creaking. The speaker button in the top bar (`#sound-btn`, next to the sections or the Menu button) starts it; it's off until asked for, remembered in localStorage `world-sound` (a remembered "on" starts on the first click or key, as browsers require), and suspended while the tab is hidden.
- `stones.js`: skipping stones. `stonePile()` for the shore; `createSkipper(scene)` flies them with no physics engine: a point under the planet's gravity (toward its centre), in 1/240 s steps; meeting the water (a sphere `RADIUS + POND.level` from the centre, inside the waterline `shoreAt`), it skips if it comes in under about 25° and over 2.2 m/s across, keeping 78% of its speed across and 55% of its speed down (as up), and leaves a ripple ring; otherwise it sinks with a plop, or lands on the sand (on the far side: "all the way across"). In `main.js` (`goToShore()` / `leaveShore()`, state `shore`): walk down to the pile and crouch at the water, a stone in your hand; press and hold (canvas, Space, or the "Hold to throw" button bottom-right) to wind up, let go to throw: held longer is harder (full at 1.1 s), where you look is where it goes, released low and level just over the water's edge the way stones skip. A short hold sinks, the sweet spot (about 0.7 s) gets 4 or 5 skips, full power makes the far shore. How it went is said in the bubble, your best is kept in localStorage `world-best-skips`, and the hint retires after the first skip. "Leave the shore" bottom-left or Esc stands you back up where you walked in.
- `render.js`: pmndrs `postprocessing` + `n8ao`: AO → HDR-only mipmap bloom (threshold 1) → AgX tone mapping → vignette + grain → SMAA, then an untouched `overlay` scene on top (the menu card in your hands). Phones skip AO, grain, and shadows.
- `hero.js`: optional hero props (AI-generated or hand-made GLBs) in `assets/models/hero/`, listed in `manifest.json`; each slot falls back to its procedural version. Slots, prompts, manifest options (`height`, `rotateY`, `roughness`, `tint`, `brightness`, `glow`) and specs: `tools/models/HERO_PROMPTS.md`; sources and licences: `tools/models/README.md`.
- Models: Kenney CC0 props merged into `assets/models/props.glb` by `tools/build-models.mjs`, which only includes models the world code clones by a literal `prop('<kit>_<name>')` (just the coconut now; the rest stay in `tools/models/` as sources). To add one, drop its GLB in `tools/models/<kit>/`, clone it with `prop('<kit>_<name>', scale)`, then run `cd tools && npm install && npm run models`.
- Content stays HTML: the top bar and menu items are `<a href>`s (JS intercepts them to open `<template id="panel-<id>">`, and serves a drink if you're seated), so it works without WebGL and is crawlable. Without WebGL2 the menu is the page. Once the panels are in charge, `main.js` points those links at `#<id>` (their real hrefs, some outbound: the résumé on Google Drive, mailto:) and `fallback()` restores them, so nothing in the menu or the drink animation ever leaves the page; the no-WebGL menu marks its outbound items ↗. Outbound links inside panels say where they go ("on Google Drive ↗").
- "Make me one" (`startMaking()` in `main.js`): the robot makes that recipe (`bar.make`), and a caption above the bottom buttons (`#making`: the drink, step n of N, what it's doing, progress dots; shown on phones too, where the bubble isn't) narrates it. "Skip to the drink" bottom-right or Esc jumps to the finished drink; "Leave the bar" stops it. From anywhere on the planet it walks you to your stool first. While it's made you lean in over the counter (the view narrows to about half its field, two thirds on phones so the whole workspace fits) and your eyes follow the work: the vessel being poured into, the shaker while it shakes, the glass for the rest, then the drink as it slides over (`focus()` on the job, eased like a head turn; snapped under reduced motion); you sit back once it's in front of you. Dragging to look is off while you lean in, and the menu (card, Menu button, E) finishes the drink first. Ordering from the menu meanwhile finishes the drink first; the bartender's chatter waits.
- The hammock (`lieInHammock()` / `getOutOfHammock()` in `main.js`, state `hammock`): the same kind of continuous first-person body motion as the bar and the fire. Step up to its side, turn round and sit on its edge (it takes your weight: `setLoad`), swing your legs up and lie back looking up through the palms; it swings from you getting in and you swing with it until it settles (the lying pose lives in the swing's frame; not under reduced motion). You pick up the book left in it, held open above you, and the Reading list (`panel-shelf`) pours out of it. Closing the list lowers the book to your chest; "Reading list" bottom-right (or E) lifts it again, "Get up" bottom-left or Esc gets you out: the reverse, with the book back where it was, ending where you walked in, facing the hammock. Drag to look around while you lie there. The half turns (standing to sitting on the edge, and back) take 1.6 s, inside the 140°/s limit.
- Ordering at the bar (`order()` in `main.js`): choosing an item puts the menu back down so you can watch the robot shake the drink and slide it over (`bar.serve(id, onServed)`), then the mug lifts to you, tipped so you look into the drink, and the section's panel pours open out of the mug's mouth (`.panel.is-pouring`, a clip-path circle from `--ox/--oy`). Closing it sets the mug back down and the menu comes back up. Drinks come in the tiki mug (open top, so there's a drink to look into), coloured per section; the parrot and pineapple mugs dress the counter and shelf. Reduced motion skips the flights.
- At the bar the menu is a real card on the counter (`bar.menu`), and it is the HTML menu: `textures.js` `paintMenuCard()` paints its face from the laid-out `.menu__card` (every box, line of text, colour, focus state and its proportions), repainted on resize, pick-up and put-down. Sitting down leaves it there; clicking it (or E/Enter, or the Menu button) picks it up: `main.js` flies the 3D card to the exact rectangle the HTML menu will fill, facing the camera, then fades the HTML menu in over it and hides the card only once the page is opaque (no frame with neither). While it flies it's drawn in `render.js`'s `overlay` pass, after the grade, going from how the lamps tint it on the counter (`bar.menu.light()`) to the page's own colours, so the handoff doesn't change a pixel. × / Esc fly it back down. Clicking the card from anywhere walks you over, sits you down and picks it up. The camera never moves for this; reduced motion skips the flight.
- Testing hooks: `window.__sceneReady`, `window.__world` (state, menuHeld, cardFlying, cameraFlying, player, pipeline, SPOTS, bar, interactables, sitDown, leaveBar, pickUpMenu, putDownMenu, pick, sitAtFire, leaveFire, eatIt, roaster, roast, lieInHammock, getOutOfHammock, lying, goToShore, leaveShore, skipper, stoneInHand, throwStone(holdSeconds) (and `window.__lastThrow`, how the last one went), make(i), making, job: the drink in progress, whose `seek(k)` holds it on step k and `steps` lists them; `bar.robot.debug()` gives each hand's reach target and tip), `?test=1` freezes ambient time, disables motion, and allows large time steps so walks finish under software rendering. Under SwiftShader, emulate `prefers-reduced-motion` too: CSS fades barely advance while WebGL frames take seconds.
- Three.js is pinned once (`three` in `_layouts/world.html`), and so are postprocessing and n8ao. Keep every entry on a minified build: `three.module.min.js` imports the unminified `three.core.js` (1.4 MB), so the map redirects that URL to `three.core.min.js`; addons the world imports get jsDelivr's `.min.js` by name. A new world module goes in the modulepreload list there too.
- Performance: the carved tiki face is drawn sharp and blurred once (a canvas `filter` on every shape cost seconds of load); point-light shadows (the campfire) only update within 28 m of the camera; hero textures are 256–512px except the bar's posts (1024 colour). Measure before adding weight.

### Styling and scripts
- `assets/css/site.css`: the site-wide stylesheet (`assets/css/world.css` adds the homepage world on top). Colors are custom properties on `:root` with three themes: light (default), dark a.k.a. space (Milky Way background; system preference or chosen), terminal (chosen). New components should use the tokens, never raw colors.
- `assets/js/site.js`: theme cycling (auto → light → dark → terminal) and `window.nextLaunch()` / `window.tMinus()`, which fill any `[data-launch]` block (cached in localStorage for an hour; the API allows 15 requests/hour/IP); `window.moonTonight()`, `window.issNow()` (wheretheiss.at, no key, about 1 request/s allowed) and `window.fillSky(el)`, which fill a `[data-sky]` block (the telescope's "Up there tonight": the moon's phase, and the ISS live every 5 s with its distance from Philadelphia). No jQuery.
- `assets/css/normalize.css` is kept only for `recipe_tracker/`.
- Fonts: Fraunces (display), Inter (body), JetBrains Mono (labels/code) from Google Fonts.
